## 2. Setup do Canva (uma vez, 5 min)

**Criar design → `1080 x 1350 px`.**

Cores — são as do app, copie o hex:

| Uso | Hex |
|---|---|
| Fundo | `#0c1220` |
| Card / caixa interna | `#151e31` |
| Borda | `#26334d` |
| Destaque (laranja) | `#f97316` |
| Texto principal | `#ffffff` |
| Texto secundário | `#94a3b8` |

Fontes — **as mesmas do app**, e as duas são grátis no Canva:

- **Sora** → títulos (Bold/ExtraBold)
- **Inter** → corpo e rodapé (Regular/Medium)

Medidas que funcionam neste tamanho de tela:

- Margem: **80 px** de cada lado
- Título: Sora Bold, **96 px**, entrelinha 1.1
- Subtítulo: Inter Regular, **42 px**, cor `#94a3b8`
- Rodapé (`arenahub.website`): Inter Medium, **32 px**, laranja

> **Faça o #1 com calma e use "Duplicar página" para os outros 8.** Fundo, fonte e margem idênticos é o que faz o grid parecer profissional. Grid bonito não é design bom — é design **repetido**.

Para os posts com print: busque `phone mockup` nos elementos do Canva e coloque o print dentro da moldura. Fica muito melhor que print solto.
